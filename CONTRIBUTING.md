# Contributing to php-csp-audit

Thanks for taking the time to help! Every contribution counts: bug reports, ideas, docs and code.

## Quick start

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Make your change, keeping it small and focused
3. Run the project locally and make sure it still works
4. Open a pull request describing **what** changed and **why**

## Good first issues

New here? Look for issues labelled [good first issue](https://github.com/ajendras/php-csp-audit/labels/good%20first%20issue): they are small and well described.

## Reporting bugs

Open an [issue](https://github.com/ajendras/php-csp-audit/issues/new/choose) with the steps to reproduce, what you expected and what happened.

## Code style

Follow the style of the code around your change. Clear names and small functions beat clever code.

## Questions

Use [Discussions](https://github.com/ajendras/php-csp-audit/discussions) for questions and ideas.
